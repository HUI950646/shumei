# Sentinel —— 基于多模态数据融合的实时目标检测与风险感知中枢

> 问道智行 · 参赛组别：自主命题——移动与网络应用开发
> **多模融感，智析路险**

Sentinel 把毫米波雷达与视觉两路数据融合到同一 BEV 地面坐标系，输出统一的实时目标列表，并在此基础上计算**各向异性连续空间风险场**——把"检测框"升级为"风险分布"，用于提前预判潜在冲突。

## 系统能力

| 环节 | 实现 |
| --- | --- |
| 雷达接入 | TCR300 毫米波雷达，TCP/IP 50000，原始字节流拆包校验帧头帧尾 |
| 视觉接入 | 网络摄像头 RTSP + YOLOv8 本地推理，检测人 / 车等六类目标 |
| 时空对齐 | 雷达 100ms、视频约 33ms；时间同步 + 地面单应矩阵标定，未标定自动进入 `uncalibrated` 模式 |
| 目标关联 | BEV 统一坐标 → 最近邻 1.5m 阈值 → 匈牙利算法一对一匹配；单源目标保留但降低置信度 |
| 风险场 | 距离、速度、类别、方向四因子合成；各向异性椭圆核，多目标叠加后饱和到 [0,1] |
| 工程优化 | 只计算目标 10m 半径内的网格点；三态状态机分级降级（有效 / 过期 / 未标定） |
| 展示与回放 | Fastify + WebSocket 10Hz 推送；Vue 3 驾驶舱四个页签；全程可回放、可定位 |

## 界面

- `/#/welcome` 入口页：全屏道路实景 + 作品主题 + 进入系统
- `/#/login` 登录 / 注册：图形验证码（前端 Canvas 生成）、登录注册切换、粒子背景
- `/#/cockpit` 驾驶舱：总览（摄像头 + 雷达小地图 + 风险场）/ 雷达探测 / 摄像头感知 / 风险场

> 登录与注册目前是**纯前端演示**：验证码在浏览器本地生成校验，没有账号后端，登录成功后直接进入驾驶舱。接入真实账号体系时，验证码必须改为服务端签发。

## 技术栈

- 前端：Vue 3.5 + TypeScript + Pinia + Vue Router + ECharts 6，Vite 7，Vitest 4
- 后端：Node.js ≥ 22，Fastify 5 + 原生 `ws`，TypeScript 编译到 `dist`
- 推理：Python 3.10/3.11 + PyTorch + Ultralytics YOLOv8（CPU 或 CUDA）
- 硬件：TCR300 毫米波雷达、网络摄像头、两块有线网卡或交换机

## 目录

```
web/                前端源码（src）+ 构建产物（dist）
sentinel-backend/   后端源码（src）+ 摄像头采集脚本（scripts）
models/             yolov8n.pt 检测模型
config/             设备地址、网卡与 Python 路径配置
验证记录/            实测截图、验证 JSON 与打包检查结果
launch.mjs          启动入口：live 实时硬件 / recording 历史回放
settings.mjs        读取 config 并拼装环境变量
```

## 本地运行

```bash
cd sentinel-backend && npm ci
cd ../web && npm ci

# 历史实测回放（不需要硬件）
node launch.mjs recording      # http://127.0.0.1:4173/

# 实时硬件（需先配置 config/devices.json 与摄像头 Python 环境）
node launch.mjs live
```

自检：

```bash
node launch.mjs --check     # 检查配置路径、模型与构建产物
node check-devices.mjs      # 检查雷达与摄像头连通性
```

## 未包含在本仓库的内容

为保证仓库可克隆，以下**派生大文件**未提交（合计约 465 MB）：

- `数据保存/`：现场实测记录（雷达 / 视觉 / 融合 CSV 与 268 MB 录像），**历史回放依赖它**
- `sentinel-backend/media/`：回放用录像与 787 帧采样图
- `web/dist/mock/`：前端 mock 演示帧（`public/mock` 已保留）

拿到原始打包数据后，按原结构放回对应目录即可直接回放。

## 验证结果

- 后端测试 **19 passed**，前端测试 27 passed / 1 skipped
- 实测记录 238.6 秒：录像 787 帧、视觉检测 258 条、雷达目标 483 条、风险快照 451 条（其中 290 条有效场）
- 摄像头推理：2 线程 P50 215 ms，8 线程 P50 274 ms

## 说明

- 坐标：地面局部坐标，x 向东、y 向北（传感器轴向现场未最终确认，界面标注"北向待标定"）
- 风险值是本项目定义的**相对风险指标**，由距离 / 闭合速度 / 近似 TTC 合成，**不是事故发生概率**
- 入口页与登录页背景图由团队提供
